# NCM Converter

一个 Android 应用，用于将网易云音乐的 NCM 加密格式转换为标准音频格式（FLAC/MP3）。

---

## 功能特性

- 📁 使用 SAF (Storage Access Framework) 安全访问文件
- 🔓 本地解密 NCM 文件，无需联网
- 🎵 自动写入歌曲元数据（标题、艺术家、专辑、封面）
- 📊 历史记录日志，追踪转换结果
- ⚙️ 可配置的冲突处理策略（跳过/覆盖/重命名）

---

## ⚠️ V1 版本能力边界说明

### 1. 覆盖策略的限制

> **在部分设备上，"覆盖"策略会自动回退为"创建新文件"**

**原因**：Android 10+ 引入了分区存储 (Scoped Storage) 限制。应用只能覆盖**自己创建的文件**。如果目标文件是由其他应用（如文件管理器、旧版本 App）创建的，系统会拒绝覆盖请求。

**表现**：
- 选择"覆盖"策略时，可能会生成 `歌曲名(1).flac`
- 历史记录会显示状态：**"无法覆盖，已保存为新文件"**
- 这是 Android 系统级限制，非 App bug

**解决方案**：
- 使用"重命名"策略可以避免这个问题
- 手动删除旧文件后重新转换

---

### 2. FLAC 封面写入限制

> **FLAC 格式目前不写入封面图片**

**原因**：Android 的 `MediaMetadataRetriever` 和标准库对 FLAC 封面写入支持有限。需要引入额外的第三方库（如 JAudioTagger）才能实现，这会显著增加 APK 体积。

**表现**：
- MP3 文件会正常显示封面
- FLAC 文件在部分播放器中不显示封面
- 元数据（标题、艺术家、专辑）会正常写入

**计划**：V2 版本可能引入 FLAC 封面支持

---

### 3. 历史记录的定位

> **历史记录是"转换日志"，不是"文件管理器"**

**设计目的**：
- 记录转换结果（成功/跳过/失败/回退）
- 帮助用户了解发生了什么
- 定位输出文件路径

**不支持的功能**：
- ❌ 从历史记录直接播放音乐
- ❌ 批量管理/删除历史文件
- ❌ 重试失败的转换
- ❌ 无限历史（保留最近 200 条）

---

### 4. 文件权限限制

> **无法对非本应用创建的文件执行强制操作**

这是 Android 分区存储的核心限制：
- 无法强制覆盖其他 App 创建的同名文件
- 无法删除非本应用创建的文件
- 即使有 `MANAGE_EXTERNAL_STORAGE` 权限，部分操作仍受限

**影响**：
- 如果 Music 目录中已有同名文件（非本 App 创建），覆盖可能失败
- 这不是 bug，是 Android 的安全设计

## 技术架构

```
┌─────────────────────────────────────────────────┐
│                    UI Layer                      │
│  MainActivity / MainScreen / HistoryScreen       │
├─────────────────────────────────────────────────┤
│                  Domain Layer                    │
│  ConvertUseCase / ScanNcmUseCase                 │
├─────────────────────────────────────────────────┤
│                  Infra Layer                     │
│  SAFManager / FileCopier / NcmDecoder           │
│  TagWriter / OutputWriter / HistoryRepository   │
├─────────────────────────────────────────────────┤
│                   NDK Layer                      │
│  libnbncm.so (C++ 解密库)                        │
└─────────────────────────────────────────────────┘
```
